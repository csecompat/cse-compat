Keep your Custom Search code. Change one URL.

Google retires the Custom Search JSON API on January 1, 2027. cse-compat is an open-source Cloudflare Worker that serves the same endpoint, parameters, response schema, and error envelope — backed by your own key from a modern search provider. Your application code never finds out Google left.

What "drop-in" means here

The contract, byte for byte

items[] with htmlSnippet highlighting, queries.nextPage pagination, honest totalResults, num/start limits enforced with Google's exact 400s, quota as 429 RESOURCE_EXHAUSTED — never a 402 your client library has no case for. Pinned by a public conformance test suite.

Bring your own key

You plug in your own Brave Search API or serper.dev key and stay their direct customer. cse-compat resells nothing and marks up nothing — it is a translation layer, Apache-2.0 licensed, and the code is public.

Built to fail over

Per-provider circuit breaker, timeout budgets, automatic failover, and pagination that stays on one index so page 2 never skips or repeats. Stateless by design: queries are never logged or stored.

Self-host in three steps

Deploy the worker to your Cloudflare account.

git clone github.com/YOURNAME/cse-compat && cd cse-compat
npm install && npx wrangler deploy

Add your own upstream key — one provider is enough to start.

npx wrangler secret put BRAVE_API_KEY   # or SERPER_API_KEY

Point your app's base URL at the worker. That's the migration.

SEARCH_BASE=https://cse.yourdomain.workers.dev/customsearch/v1

Managed version — waitlist

Don't want to run a worker? The hosted version adds multi-provider fallback, cx site-restriction profiles, usage analytics, and an SLA — same endpoint, zero infrastructure on your side. Launching before the shutdown.
