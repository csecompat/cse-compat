Apache-2.0, self-hostable forever

The core is open source. Run it on Cloudflare's free tier and it costs you nothing but your own search-API usage. No lock-in, which is the point of the whole project.

Self-host

Deployed in three steps.

Deploy the worker to your Cloudflare account.

git clone github.com/csecompat/cse-compat
cd cse-compat
npm i && npx wrangler deploy

Add your upstream key. One provider is enough.

npx wrangler secret put \
  BRAVE_API_KEY
# or SERPER_API_KEY

Change the base URL. That's the migration.

SEARCH_BASE=
https://cse.you.workers.dev
  /customsearch/v1

Managed version

Zero infrastructure on your side.

The hosted version adds multi-provider fallback, cx site-restriction profiles, usage analytics, and an SLA. Same endpoint, no worker to run. Launching before the shutdown.
